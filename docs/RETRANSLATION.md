# Unity Underground 재번역 작업 지침

현재 번역은 5,181개의 영문 문자열을 한국어로 옮긴 상태지만, 문맥 없이 문장 단위로 번역된 항목과 직역식 용어가 섞여 있습니다. 이 문서는 기존 번역을 폐기하지 않고 참고 자료로 남기면서, 재번역 결과를 안전하게 교체하기 위한 기준을 정리합니다.

## 확인된 문제 유형

- 오탈자와 한글·영문 혼입: `말떫함`, `칼리스타n`, `무 아흐m`
- 단계형 마법부여의 직역: `위대한 피해`, `매우 위대한 방어`
- 같은 대화 안에서 `당신`, `그대`, `너`, 존댓말과 반말이 불규칙하게 혼용됨
- 짧은 문자열만 따로 번역해 조사와 동적 문장 결합이 어색해짐
- 형식 검증은 통과하지만 실제 한국어 품질이 낮은 항목이 존재함

## 번역 원칙

### 시스템과 UI

- 안내문은 간결한 `~합니다`, 버튼과 상태명은 명사형을 사용합니다.
- 원문에 없는 주어 `당신`을 습관적으로 덧붙이지 않습니다.
- 게임에서 조합되는 짧은 조각은 완성 문장이 아니라 결합 결과를 기준으로 번역합니다.

### 아이템, 기술, 주문

- 동일 계열의 단계 표현을 먼저 확정한 뒤 전 항목에 통일합니다.
- `Great`, `Very Great`, `Tremendous`, `Unsurpassed`를 단어별로 직역하지 않습니다.
- 고유명사와 룬 음역은 용어집에서 한 번만 정하고 변형하지 않습니다.

### NPC 대화

- 인접 문자열을 함께 읽어 화자와 응답 관계를 추정합니다.
- `thou/thee`가 있다는 이유만으로 모든 대사를 `~하노라`로 만들지 않습니다.
- 비문, 묘비, 예언, 의식문처럼 실제로 고풍스러운 문맥에서만 고풍체를 사용합니다.
- 고블린과 비인간 종족의 서툰 말투는 의도적으로 단순하게 쓰되 현대 인터넷 말투는 피합니다.
- 플레이어 선택지는 기본적으로 자연스러운 중립체를 쓰고, 모욕·위협 선택지만 거칠게 번역합니다.

## 작업 흐름

### 1. 현재 번역 감사

```bash
node tools/audit_retranslation.js
```

결과는 `tools/output/retranslation_audit.json`에 생성됩니다.

- `structuralIssues`: 플레이스홀더, 제어 코드, 줄바꿈 등 런타임 안전성 문제
- `reviewIssues`: 오탈자, 영문 혼입, 직역 가능성이 높은 용어 등 사람이 검토할 문제

### 2. 재번역 배치 생성

```bash
node tools/build_retranslation_batches.js
```

기본값은 문자열 순서를 유지하고 각 항목 앞뒤 3개 문자열을 문맥으로 붙입니다. 결과는 `tools/output/retranslation_batches`에 생성됩니다.

특정 범위만 만들려면 다음처럼 실행합니다.

```bash
node tools/build_retranslation_batches.js --from-id 1 --to-id 500
```

### 3. 결과 적용 전 검증

재번역 결과를 `global_text_map.json`에 합친 뒤 기존 검증과 새 감사를 모두 실행합니다.

```bash
node tools/translate_uu.js validate
node tools/audit_retranslation.js
```

`structuralIssueCount`가 0이 아닌 결과는 게임 파일에 적용하지 않습니다. `reviewIssues`는 자동 오류로 단정하지 말고 문맥에 따라 사람이 검토합니다.

## 권장 진행 순서

1. UI, 시스템 메시지, 상태 표현
2. 아이템, 기술, 주문, 마법부여 단계
3. 책, 표지판, 묘비, 컷신
4. NPC 대화와 플레이어 선택지
5. 게임 내 출력 확인과 동적 문장 보정

현재 한국어는 재번역의 참고 자료일 뿐 정답으로 취급하지 않습니다.
