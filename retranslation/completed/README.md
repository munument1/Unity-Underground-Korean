# 완료된 재번역 묶음

이 디렉터리는 원문 블록과 현재 번역을 대조해 사람이 검토한 재번역 제안 묶음을 보관합니다.

각 `bundle_XX.json`은 다음을 포함합니다.

- 묶음 통계와 검증 결과
- 원래 `blockId`, `stringId`, 영문 원문
- 기존 한국어 참고문
- 검토가 끝난 `proposedTranslation`
- 항목별 검토 메모와 앞뒤 문맥

## 진행 현황

현재까지 **1,708개 항목**을 검토했고 **791개를 수정하거나 재번역**했습니다.

전체 7,091개 영문 위치 기준 진행률은 약 **24.1%**이며, 149개 작업 배치 중 33개를 완료했습니다.

이 자료는 검토용 제안입니다. 실제 `translations/block_*.json` 및 `global_text_map.json`에 병합하기 전 구조·토큰 검증과 게임 내 확인이 필요합니다.
